# cube_with_hole demo

This directory is generated by:

```bash
mesh2cad-demo examples/cube_with_hole
```

- `cube_with_hole.stl` is the faceted, watertight input.
- `cube_with_hole.step` is the analytic OpenCascade BRep.
- `cube_with_hole.metrics.json` records six planes, one cylinder, full coverage, and both analytic
  surface and point-to-BRep reconstruction errors.

Regenerating the directory is deterministic apart from STEP header timestamps.
